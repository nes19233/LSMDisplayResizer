# Sicherheit

## Sicherheitslücke melden

Bitte Sicherheitslücken **nicht** als öffentliches Issue melden. Stattdessen über GitHub privat melden:
Registerkarte **Security** → **Report a vulnerability** in diesem Repository.

Hilfreich sind eine kurze Beschreibung, betroffene Version und – wenn möglich – Schritte zum Nachvollziehen.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils neueste veröffentlichte Version (siehe Releases).

## Hinweise zur App

- Die App läuft ohne Administratorrechte und fordert keine an.
- Sie sendet keine Daten ins Internet und hat keine Update- oder Telemetriefunktion.
- Einstellungen und Log liegen ausschließlich lokal in `%AppData%\LSM Display Resizer\`.
